# Jido (自動)

## A Python CLI tool that automates the creation of Japanese Anki flashcards

This program is designed to automate the creation of Japanese Anki flashcards with minimal user input. This is done either word-by-word through manual input, or by importing a CSV file. When ready, it will produce a .apkg file which can then be imported into Anki. The data included on the cards are as follows:

* The expression, as typed, including words usually written in kana but that have rarely-used kanji
* The meaning of the expression
* The reading of the expression, including furigana
* The pitch accent of the expression, including an SVG diagram
* A sentence in Japanese with surrounding context at a level designated by the user (i.e., JLPT N4)
* An English translation of the Japanese sentence
* Audio of the expression
* Audio of the Japanese sentence
* Additional notes and information

Furthermore, two separate cards are created for each word: one in which the user is tested by the expression, and one where they are tested by the audio of both the expression and the Japanese sentence.

## Requirements

* Python 3.12+
* Anthropic API key
* Microsoft Azure Cognitive Services API key and enpoint

## Future plans

This project is entirely usable in its current state but there are future improvements planned, including but not limited to the following:

### Database integration

The next phase of this project is the implementation of a SQLlite database to store every card created. Once stored, if another user were to lookup the exact same expression at the same user level, instead of querying each API and dataset, it will instead search the database to provide a faster (and cheaper) card.

This is also a major preparation step to opening this project to public use.

### Subtitle and text import via NLP

A future phase of this project is the addition of a morphological analysis of text files (i.e., subtitle files). This would allow a user to upload a text file and select a percentage of words (i.e., top 85%), and the program would analyze the file and determine that percentage of the most common words excluding particles, auxiliary verbs, etc. It would then use surrounding context to determine the meanings of each word and generate an Anki deck containing those words.

### Proper CLI interface and website

The current final goal with this project is to open it to public use through a proper CLI interface and eventually a web application.

## Known issues

There are several currently known issues of varying degrees, including the following:

* The pitch accent data is not 100% accurate. No relaible method has been found to meaningfully ensure accurate pitch accent data because it can vary based on the meaning of a word.
* The sentences generated by Anthropic API may not always be perfect. This is an inevitable result of using an LLM.
* The audio for some expressions is very rarely mispronounced.
